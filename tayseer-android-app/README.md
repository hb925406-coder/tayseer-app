# 📱 تطبيق تيسير (Tayseer) لإدارة الطلاب والحضور والتقييمات

تطبيق أندرويد أصلي (Native Android) متكامل مبني بلغة **Kotlin** وأحدث تقنيات **Jetpack Compose** و **Material 3** وقاعدة بيانات محلية **Room SQLite**.

التطبيق مصمم خصيصاً للمدارس، المعاهد، وحلقات تحفيظ القرآن الكريم والمراكز التعليمية، ويعمل **دون الحاجة للاتصال بالإنترنت نهائياً (Offline 100%)**، مع دعم كامل للغة العربية واتجاه اليمين لليسار (RTL).

---

## 🌟 أبرز ميزات تطبيق تيسير

1. **إدارة متكاملة للأدوار والصلاحيات:**
   * **الإدارة:** تحكم كامل في الأقسام، الحلقات/المستويات، المعلمين، والطلاب.
   * **المعلم:** تسجيل الحضور وتقييم الطلاب في مواده وحلقاته فقط.
   * **ولي الأمر:** بوابة مخصصة ومحمية برمز وصول (PIN) لمتابعة تقرير ابنه وحضوره وتقييماته فقط.
2. **تسجيل الحضور والغياب اليومي بنقرة زر:**
   * 6 حالات حضور متميزة بالألوان: حاضر، غائب، متأخر، مستأذن، غائب بعذر، هارب.
   * إمكانية توثيق سبب الغياب/التأخير واسم الموثق.
   * منع تكرار التسجيل لنفس الطالب في نفس اليوم والحلقة.
3. **تقييم الطلاب والسلوكيات:**
   * وسوم تفاعلية واضحة: (حفظه 📖، لم يحفظ ⚠️، مميز ⭐، مؤدب 🤝، نسيان الكتب 📚، ملاحظة مخصصة ✍️).
   * إمكانية إضافة ملاحظات المعلم وحفظ سجل تاريخي كامل لكل طالب.
4. **خلاصة الطالب وتصدير تقارير PDF:**
   * ملف شخصي شامل يوضح نسب الانضباط وتفاصيل الحضور والتقييمات.
   * تصدير فوري لتقرير متابعة رسمي بتنسيق **PDF** باللغة العربية مع إمكانية مشاركته مباشرة عبر WhatsApp أو البريد أو الطباعة.
5. **التقويم الهجري والميلادي:**
   * اعتماد التقويم الهجري كافتراضي مع عرض موازي للميلادي وخيار للتبديل.
   * إمكانية ضبط اليوم الهجري (+1 / -1) لمطابقة رؤية الهلال بدقة.
6. **البيانات والنسخ الاحتياطي:**
   * تخزين محلي آمن ومشفر لكلمات المرور (SHA-256 مع Salt).
   * زر لتوليد بيانات تجريبية جاهزة للاختبار، وزر للمسح النهائي.
   * استيراد قوائم الطلاب عبر ملفات CSV.

## 🛠️ البنية التقنية (Tech Stack)

* **اللغة:** Kotlin 1.9.24
* **واجهات المستخدم:** Jetpack Compose + Material 3 (Pure Declarative UI)
* **قاعدة البيانات المحلية:** Room Database (SQLite) 2.6.1
* **إدارة الحالة:** Android Architecture Components (ViewModel, StateFlow, Coroutines)
* **التنقل:** Navigation Compose
* **تصدير التقارير:** Android Native `PdfDocument` & `FileProvider`
* **نظام البناء:** Gradle 8.7 مع GitHub Actions للإنشاء السحابي المجاني

## 🚀 كيفية بناء ملف الـ APK عبر سحابة GitHub مجاناً

لقد تم تجهيز ملف البناء التلقائي في المسار `.github/workflows/android-apk.yml`. لا تحتاج لتثبيت أي برامج على حاسوبك:

1. **رفع المشروع إلى مستودعك على GitHub:**
   * انسخ ملفات المشروع وارفعها إلى مستودعك `tayseer-app`.
2. **تشغيل البناء التلقائي:**
   * بمجرد رفع الملفات (Push)، سيبدأ GitHub تلقائياً ببناء التطبيق.
   * أو اذهب إلى تبويب **Actions** في صفحة مستودعك، واختر سير العمل **Build Tayseer Android APK**، ثم اضغط على زر **Run workflow**.
3. **تحميل ملف الـ APK:**
   * انتظر دقيقتين حتى تظهر علامة الصح الخضراء (✔).
   * اضغط على اسم عملية البناء المكتملة.
   * انزل لأسفل الصفحة عند قسم **Artifacts**، ستجد ملفاً باسم:
     `Tayseer-App-Debug-APK`
   * اضغط عليه لتحميله، وفك ضغطه لتحصل على ملف `app-debug.apk` الجاهز للتثبيت!

## 📲 خطوات تثبيت الـ APK على هاتف Android وهواتف Redmi / Xiaomi

1. **نقل الملف إلى الهاتف:**
   * أرسل ملف `app-debug.apk` إلى هاتفك عبر كابل USB، أو أرسله لنفسك في رسالة WhatsApp أو Telegram، أو حمله عبر المتصفح.
2. **السماح بالتثبيت من مصادر غير معروفة:**
   * عند الضغط على ملف الـ APK لتثبيته، قد تظهر لك رسالة من نظام أندرويد تطلب السماح للمتصفح أو مدير الملفات بتثبيت التطبيقات. اضغط **الإعدادات (Settings)** وفعّل خيار **السماح من هذا المصدر (Allow from this source)**.
3. **ملاحظة خاصة بهواتف Redmi / Xiaomi (واجهات MIUI و HyperOS):**
   * قد تظهر شاشة حماية تحذيرية برتقالية تعد تنازلياً 10 ثوانٍ ("تنبيه أمان"). ضع علامة صح على "أنا على علم بالمخاطر المحتملة" ثم اضغط **موافق (OK)**.
   * إذا ظهر تحذير **Google Play Protect** (لأن التطبيق جديد ومبني كنسخة تجريبية ولم يُنشر بعد على المتجر العام)، اضغط على **تفاصيل إضافية (More details)** ثم اختر **التثبيت على أي حال (Install anyway)**.
4. **بدء الاستخدام:**
   * افتح تطبيق **تيسير** لأول مرة، وسيطلب منك التطبيق مباشرة تعيين كلمة مرور لمدير النظام (`admin`). عيّن كلمة المرور وابدأ إدارة طلابك بأمان تام!

## ⚖️ الفرق بين APK التجريبي (Debug) ونسخة الإصدار النهائي (Release)

* **نسخة الـ APK التجريبية (Debug APK):**
  * النسخة التي يقوم GitHub Actions باستخراجها الآن.
  * موقعة بمفتاح تشفير تجريبي افتراضي (`debug.keystore`).
  * تتيح لك تثبيت التطبيق وتجربته فوراً على أي هاتف بدون قيود، وهي مخصصة للاختبار والاستخدام الداخلي.
* **نسخة الإصدار النهائي الموقعة (Signed Release APK / AAB):**
  * تتطلب إنشاء مفتاح تشفير خاص بالمطور (`.jks / keystore`) يُحفظ في مكان سري.
  * يتم تفعيل ضغط وتشفير الأكواد (R8/ProGuard) لتصغير حجم التطبيق ومنع التلاعب به.
  * هي النسخة الإلزامية التي تُرفع على متجر **Google Play Console** لنشر التطبيق للعامة.
